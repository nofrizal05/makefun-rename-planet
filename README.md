One funny new name for a planet in our solar system, plus the why, in a single line under 200 characters — an entry for the [Rename the Planet](https://make.fun/bounty/u-motasimfuad-rename-the-planet-094b0369) competition on [make.fun](https://make.fun).

## The line

> Jupiter is now 'All-You-Can-Eat' — it swallowed the other planets' lunches for 4.5 billion years and never apologised.

(118 characters)

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed).
